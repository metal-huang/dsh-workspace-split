# DSH 多会话并置

把多个进行中的会话并排放在一个窗口里持续可见，每个格子都能直接输入。
用于并行监督多个项目，省掉挨个点进去查看的来回切换。

它是 DSH（DeepSeek Harness）桌面端的一个插件。

## 它不做什么

它不重新实现会话界面。会话渲染、多会话并发存活、进度信号这几件事
DSH 已经提供了能力，本插件只做两层：布局编排、当前格标记。

会话界面直接复用 DSH 原生渲染器，因此自动跟随 DSH 升级。
