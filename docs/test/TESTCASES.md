# 分屏插件测试用例

## 环境
- DSH web profile，Windows，dsh 0.2.1-rc.2
- 插件包 `dsh-workspace-split` 已 link 安装

## 用例

### TC-01 插件加载
- 步骤：启动 `dsh web`，浏览器打开首页
- 预期：侧边栏正常渲染，无 "Failed to load plugins" 报错

### TC-02 入口可见性（hero 页面）
- 步骤：未选任何会话，停留在 hero 页面
- 预期：「⊞ Split」按钮出现在 hero 区域 options 行（「标准模式」旁）

### TC-03 切换到分屏
- 步骤：hero 页面点「⊞ Split」
- 预期：主区域从 hero 切换为分屏面板，显示 "Split view placeholder"

### TC-04 切回会话
- 步骤：分屏面板下再点「⊞ Split」
- 预期：主区域恢复 hero 页面

### TC-05 入口可见性（激活会话）
- 步骤：进入一个激活会话（有对话记录）
- 预期：「⊞ Split」按钮出现在会话 header actions 行

### TC-06 激活会话切换分屏
- 步骤：激活会话页面点「⊞ Split」
- 预期：主区域切换为分屏面板；再点恢复会话内容

### TC-07 分屏面板格渲染
- 步骤：进入分屏面板
- 预期：显示 N 个格子，每格有会话选择器占位

### TC-08 刷新持久化
- 步骤：分屏状态下刷新页面，再点「⊞ 分屏」
- 预期：格子分配恢复（gridSize + 每格选中的会话）

### TC-09 格子内会话内容渲染
- 步骤：格子选中会话后，格内显示该会话的消息流
- 预期：user/message、assistant/message、turn 分隔线等内容按序渲染，自动滚动到底部

### TC-10 格子内直接输入
- 步骤：格子底部输入框输入文字，回车或点「发送」
- 预期：消息通过 session.prompt() 进入会话，输入框清空，焦点保持

### TC-11 状态灯
- 步骤：格子 header 左侧圆点显示会话运行状态
- 预期：运行中绿色，空闲灰色

### TC-12 分屏状态自动恢复
- 步骤：分屏激活状态下刷新页面
- 预期：页面加载后自动回到分屏，格子分配完整

### TC-13 网格选择器（仿插入表格的悬停交互）
- 步骤：点工具栏的「网格」按钮，在 10×10 方格上悬停
- 预期：弹出的面板标题实时显示「N 行 × M 列 · 共 K 格」，已选方格高亮；
  点击后面板关闭并切换布局；键盘方向键可移动选择，回车生效

### TC-13a 软限制（6 格）
- 步骤：悬停选中 2×4（8 格）并点击
- 预期：弹出确认框「打开 8 个格子？」并提示可能卡顿；取消不改变布局，
  「仍然继续」后布局变为 2 行 4 列

### TC-13b 硬顶（10 格）与解锁提示
- 步骤：悬停选中 3×4（12 格）并点击
- 预期：不切换布局，弹出「需要解锁 12 格」提示，说明去 设置 → 通用 →
  分屏网格 调整；面板下方同时提示「超过上限 10 格，去设置解锁」

### TC-14 上限可配置
- 步骤：设置 → 通用 → 分屏网格，把「最多格子数」改为 12，
  「超过此数须确认」改为 4
- 预期：无需重启，3×4（12 格）可经确认框生效；5 格起就弹确认框；
  分屏面板和选择器立即跟随新上限

### TC-16 旧布局迁移与缩容保留
- 步骤：localStorage 里保留旧版 `{ gridSize: 5 }` 后刷新；再切到 2×2，然后切回 3×3
- 预期：旧布局按新硬顶收敛为最接近方形的 3×3（9 格），布局不报错；
  缩到 2×2 时被隐藏的格子分配不丢失，切回 3×3 后恢复

### TC-17 键盘与窄窗口
- 步骤：键盘打开选择器，选中 2×4 触发确认框；Tab 到「仍然继续」后等待会话更新；
  再把窗口高度压到 400px 以下
- 预期：焦点不会被会话更新抢回「取消」；取消/Esc 后焦点回到网格；
  选择面板不被主区域裁切，可滚动看到 7–10 格

### TC-15 Windows 桌面端（web profile）验证
- 步骤：Windows 上 `dsh web` 安装同一插件，打开页面操作
- 预期：与 WSL 行为一致，大目录（600+ 会话）下正常

## 自动化回归（E2E）

`npm run test:e2e` 用本机 Chrome/Chromium 的无头模式跑 `test/e2e/`：静态服务起一个
复刻桌面端 footer 结构的页面（含 slot 的 `display: contents` 包裹层、mobile 入口
与账号行），加载插件真实的 `src/layout.js`。

- TC-E2E-01 侧栏控件垂直居中对齐账号行：断言实测偏移 ≈ 60.3px、控件中心与账号行
  中心偏差 < 0.6px。这条是桌面端「图标浮在两行之间」的回归用例——用旧写法
  （`parentElement.nextElementSibling`）会直接失败。
- TC-E2E-02 折叠态：shell 的 `data-sidebar-collapsed="true"` 必须压过内联
  `translateY`，计算样式回到 `none`。

找不到浏览器时整组跳过（可设 `DSWS_CHROME` 指定路径）。

## 已知限制
- 完整发送链路（prompt → LLM 回复）需要 API key，测试环境未覆盖
- 格子内消息为只读简版渲染，无 Markdown/代码高亮
- 多显示器场景使用浏览器多窗口（每窗口独立 localStorage）
