# SPEC 文档规范

> 文档版本：v1（2026-10-22 立版）· 实质更新时递增版本号并改此日期

## 本页性质

本页是**指针页**。文档规范的权威条文在真源仓 `engineering-standards`
（两份姊妹规范：文档命名规范、文档驱动开发流转）。真源仓在本机有固定位置，
其路径不写入本仓库，以避免泄露本地环境信息。

本页只记两件事：本仓库采用哪些规范，以及本仓库自己的裁剪选择。

## 本仓库采用

| 项目 | 采用内容 |
|---|---|
| 类型词表 | 七类：PRD / DESIGN / TECH / IMPL / CR / SPEC / BACKLOG |
| 目录即大类 | `docs/` 下按类型设子目录，另设 `archive/` |
| 快照类命名 | `YYYYMMDD_类型_主题.md`，日期前置 |
| 活文档命名 | `TECH_主题.md` / `SPEC_主题.md`，不带日期 |
| 归档命名 | 原文件名前缀不变，尾缀 `_归档YYYYMMDD.md` |
| 易腐值零抄写 | 计数、基线、性能数字不写进文档，只写「在哪查、怎么查」 |
| 单一真源链 | `CLAUDE.md` 指针 → 各类型文档正文，同一事实只出现在一层 |

## 本仓库的裁剪选择

- 主题一律中文，文件名不含版本后缀（修订并回原文件，历史交给 git）
- `docs/tech/` 下暂不细分 `impl/` 与 `codereview/`，有内容时再建
- 不使用 BACKLOG 的工程待办台账扩展用法，BACKLOG 只做点子备忘

## 中文写作要求

沿用全局偏好中的三条硬规则：

1. 有两字完整形式就用两字形式，禁止单字缩写；代码标识符保持英文原名
2. 禁用互联网与金融公司内部行话；术语首次出现配一句人话解释
3. 未被要求对比时，禁止「不是…而是…」这类对比句式

## 开源仓库的额外约束

本仓库面向开源，因此：

- 文档与注释中不出现本机绝对路径、用户名、邮箱等个人信息
- 引用本机文件时只写相对路径或仓库内路径
- 提交历史保持单一职责，一次提交只做一件事
