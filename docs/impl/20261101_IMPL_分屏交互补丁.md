## 关键取舍（为什么这么做）

- **下拉自绘，不用原生 `<select>`。** 原生控件的选项只能是纯文本，项目名只能当后缀；标题栏是彩色徽章，两者永远不像。代价是键盘、点外关闭、定位要自己实现，因此规则拆到 `picker.js` 做纯函数单测。
- **面板 portal 到 `document.body`。** 格子会裁剪内容（`overflow: hidden`），正文还带 `CellZoom` 的 `transform`；画在格子里的浮层会被裁掉或跟着缩放。图片预览与下拉都走 portal。
- **归档按“注册表事实”处理。** 归档只进 `ctx.workspaces.list` 的 `archivedSessionIds`，会话清单不会因此丢会话；所以格子失效判定必须同时看“还在清单里”和“没被归档”。
- **清「完成未读」是一处有意的越界依赖。** DSH 只给主视图清，公开面没有写入口；实现读实例上的确认集合并在成员缺失时降级为“亮点留着”，契约测试盯着成员名。理由与替换路径见 TECH 13.5。
- **项目徽章样式只写一份。** 标题栏与下拉共用 `projectBadgeStyle`；下拉里只是把宽度与字号压紧，避免长项目名把标题挤掉。

## 怎么验证

```bash
npm run check                 # 全档门禁（lint、重复代码、格式、单测、浏览器 E2E）
npm run build                 # 重建 packages/dsh-workspace-split/client.js（产物不入库）
npm run release               # 更新 .release/ 快照；桌面版刷新窗口即生效
```

浏览器 fixture：页面带 `?dsws-test` 或 localStorage 里 `dsws-test=1` 时才暴露
`window.__dswsTest.render(name, node, props)`，可单独渲染审批卡、过程组、模型菜单、
草稿文件条、格子标题、会话下拉、图片缩略图、图片预览等；真实页面不带这个开关。

## 踩过的坑

- **E2E 用 `.click()` 抓不到“按下即关”。** 合成事件一步到位，React 没机会在按下与松开之间刷新；真实鼠标按下的中间态才是问题现场。现在有一条“按下 → 等待 → 松开 + 点击”的用例专门盯这个。
- **DSH 新 home 首启有欢迎弹窗（遮罩层级高于插件浮层）。** 用 CDP 真实鼠标做探针时，点击会先落在遮罩上，表现为“面板被点掉”；调试浮层问题时先关掉或绕过它，或者用“按坐标命中测试”确认点到了哪里。
- **下拉的“点外关闭”必须同时豁免触发按钮与面板。** 面板是 portal，不在触发按钮的子树里；只判断触发按钮会把面板内部也当成“外面”。
- **贴近窗口底部时不能按首选高度定位。** 面板高度由内容决定，用首选高度算“上方位置”会在面板和触发按钮之间留出大段空白；应按 `bottom` 锚定。
- **重排代码会让源码形状守卫变红。** `test/split-wiring.test.js` 断言的是接线的实际写法，改那几行时一并更新片段。
