### 格子上限设置的跨 profile 同步

- 现状：上限存 `localStorage['dsws-limits']`，与布局一样按浏览器 profile 隔离；
  web 与桌面 profile 各自独立，清缓存会回到 10/6。
- 待办：若要求「设置一次到处生效」，改走 DSH settings 服务或 host 侧配置通道。
  当前实现不阻塞单机使用。

### npm test 的 glob 把 E2E 一起跑了

- 现状：`package.json` 的 `test` 是 `node --test "test/**/*.test.js"`，实测展开后 16 个
  文件，含 `test/e2e/dsh-composer.test.js` 与 `test/e2e/sidebar-align.test.js`——也就是
  `npm test`（以及 `npm run check`）会顺带启动浏览器 E2E，与 AGENTS.md 写的「check 只
  跑 lint + 重复代码 + 格式 + 测试，E2E 走 `npm run test:e2e`」不一致。
- 待办：定夺是把这个 glob 收紧成不含 `test/e2e/` 的集合，还是把 AGENTS.md 与 README
  改成「check 含 E2E」；顺带确认 CI 是否具备浏览器。

### 归档释放格子会丢掉该格未发出的草稿

- 现状：格子的草稿存在 `CellView` 的组件 state（`inputText`），不随布局持久化。会话被
  归档后格子释放、`CellView` 卸载，草稿随之丢弃；旧路径（会话离开清单）本来也这样，
  但归档是高频动作，更容易撞上。
- 待办（可二选一或都做）：释放前提示一次「该格有未发送草稿」；或把每格草稿按会话 id
  暂存，重新选中该会话时回填。当前不阻塞使用。

### 会话下拉在大量会话下的渲染开销

- 现状：`SplitCell` 每次渲染都用 `options.map` 重建下拉的行（`client.js` 的
  `pickerRows`），每格一份、覆盖整个目录；面板打开时行数组每次都是新引用，列表随之
  整表重渲。单机几百个会话时未做过渲染耗时测量。
- 待办：先用真实规模 profile 一次（打开下拉、连续按上下键、输入过滤），确认是否需要
  给行做缓存（按 `id + title + project + running` 记忆）或虚拟化；没有实测变卡之前
  不要提前优化。
- 备注：面板定位与键盘移动时的滚动已分别做过去抖（`place()` 只在真正位移时更新，
  面板自身滚动不再触发重新定位）。

### 斜杠候选菜单与主界面对齐

- 现状：分屏已支持直接输入 `/技能名 参数`，但输入 `/` 不会弹出候选；主界面会把
  Host 命令和用户技能放进同一个候选菜单。
- 目标：`/` 与 `+` 都能打开命令与技能候选；过滤、排序、键盘上下选择、鼠标选择、
  读屏描述与主界面一致；技能选中后保留字面文本，命令选中后走对应命令路径。
- 验收：不知道技能全名也能发现并调用；候选按会话更新，多个格子互不串目录；
  中英文与 IME 确认行为不回归。实施时先写 DESIGN，评估复用公开候选接口而不是复制
  主界面内部实现。

### 未认领斜杠文本的发送行为与主界面对齐

- 现状：#19 暂时把「不是已知技能」的斜杠文本保留为「未知命令」，避免在客户端命令
  尚未接入时把 `/model` 或拼错命令误发给模型；主界面在裁决未认领后会按普通 prompt
  发送原文。
- 目标：等客户端命令目录与弹层能力补齐后，恢复主界面的最终行为：未被命令或客户端
  动作认领的斜杠文本按原文进入 prompt，不再额外报「未知命令」。
- 验收：命令不会重复执行，技能不会重复加载；`/model` 等客户端命令先被正确认领，
  剩余未认领文本才允许发送。此项依赖下一条，不能单独提前放开。

### 主界面客户端命令与弹层能力对齐

- 现状：`/model`、`/permission`、`/export` 等由主界面客户端处理的命令，在分屏里
  没有完整对应行为；它们不属于 Host 命令注册表，不能按普通 Host 命令或技能处理。
- 目标：支持主界面的 popupSelect、action 与 leadingInput 三类命令路径，弹层选择、
  参数提交、附件拒绝和错误保留草稿的行为一致；无法支持的命令要明确提示，不能静默
  降级为模型输入。
- 验收：模型与权限选择在分屏和主界面结果一致；导出等 action 不进入对话轮次；
  多格子不会互相弹错会话。先确认公开接入点或推动上游开放，不直接复制客户端内部
  `CommandDirectory` 实现。
